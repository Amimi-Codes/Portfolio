# Amy Cui — Portfolio

An ocean-inspired design portfolio with an animated puzzle-piece introduction, an interactive particle field, selected projects, and a scroll-led HabitU case study.

## Pages

- `index.html` — homepage and selected work
- `habitu.html` — HabitU case study

The site uses plain HTML, CSS, and JavaScript with no build dependencies. Open `index.html` locally or serve this folder with a static web server.

The HabitU story is based on [Amy’s original case study](https://amycui4197.wixsite.com/amy-designs/copy-2-of-bloom-blog). Research themes are qualitative; the visuals do not imply numerical study findings. The HabitU mockup is from the original project.

## Accessibility

Keyboard navigation, skip links, semantic sections, descriptive image text, and reduced-motion support are included.
